# Logs Folder

This folder contains the durable history and review records of the workflow.

Use these files for:

- developer execution history
- reviewer decisions and findings
- debugger investigation records
- manually captured suggestions and improvements

Main files:

- `AI_DEVELOPER_EXECUTION_LOG.md`
- `AI_REVIEWER_REMARKS.md`
- `DEBUGGER_OUTPUT_LOG.md`
- `SUGGESTIONS_AND_IMPROVEMENTS_LOG.md`
