App Guide

Complete flow and components

📱 Main User Journey (11 Steps)

1

Splash Screen

2.5 second animated intro with branding and progress bar

2

Sign In Screen

Phone number + 4-digit PIN authentication. Pre-filled with demo credentials. "Restore Session" button for returning users.

3

Home Screen

Main dashboard with: Current status card, Monthly spending, Saved locations (clickable), Recent activity, Notification banner

4

Locations Screen

Browse 4 parking locations: Sentosa, Marina Bay, Changi, Orchard. Each shows: distance, rate, available slots. Click to select.

5

Slots Screen (Interactive)

SVG-based parking lot with 32 spots (16 Section A left, 16 Section B right). Entrance/Exit markers. Zoom +/- buttons. Drag to pan. Click spots to select. Legend shows: Available (green), Reserved (yellow dashed), Occupied (gray)

6

Reservation Details

Form with: Arrival time dropdown (30min/1hr/2hrs), Vehicle registration, Vehicle type. Fee preview card shows rate ($3.50/hr) and "Pay as you go" billing

7

Confirmation Screen

Success state with: Green checkmark icon, Slot number, Booking reference (e.g., PF-2024-ABC123), Valid until (2 hours), Vehicle info, Countdown badge, "What's Next?" info box

8

Arrival Screen

At parking lot: Shows reserved slot, time window warning (30 min to validate), QR code scan button, Manual confirm button

9

Validation/Active Session

QR scanner placeholder or manual slot entry. Once confirmed, transitions to full-screen Active Session with timer

10

Active Session (Fullscreen Modal)

Live HH:MM:SS timer, running cost ($0.71), vehicle info, "Connected" badge, "End Session" button. Updates every 1 second.

11

Payment → Receipt → Home

Payment review, "Pay Now" button, Success receipt with transaction ID, Share receipt option, Return to home

🧩 Key Components

Header Bar
App title, subtitle, back buttons, action buttons (zoom controls in slots)
Status Badges
Online (green pulsing dot) / Offline (red static dot)
Info Cards
Title, large value display, metadata. Used for status, costs, vehicle info
Buttons
Primary (green), Secondary (white), Danger (red). All with active states and disabled states
Form Controls
Text inputs, selects, password fields. All with labels and focus states
Message Boxes
Success (green), Error (red), Warning (yellow), Info (blue)
SVG Parking Lot
Interactive 2D map with 32 slots, entrance/exit, lane markers, traffic flow arrows
Timer Display
Large monospaced HH:MM:SS in gradient green. Updates every 1 second during sessions
Cost Rows
Pairs of labels and values for fee breakdowns
Bottom Navigation
4-tab bar: Home, Reserve, Sessions, Profile. Active state shown in green

⚡ User Interactions

Parking Lot (Slots Screen)
• Click any available (green) or reserved (yellow) spot to select
• Drag/mouse move to pan the map
• Scroll wheel to zoom in/out
• +/- buttons for manual zoom
• Reset button to return to default view
Navigation
• Bottom nav tabs switch between Home/Reserve/Sessions/Profile
• Back buttons in header navigate to previous screen
• Each tab maintains its own history
Form Submission
• Sign In validates phone + PIN before proceeding
• Reservation form collects vehicle info
• Validation form accepts manual slot entry
Session Timer
• Starts when user confirms parking
• Increments every 1 second
• Cost calculated in real-time at $3.50/hour
• Stops when "End Session" is clicked
Status Updates
• Online badge pulses when connected
• Offline badge shows when disconnected
• Messages appear for 3 seconds then fade

Location Object

Session Object
{ startTime, duration, cost, slot, vehicle }
