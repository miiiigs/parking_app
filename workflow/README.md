# Workflow Folder Map

This folder is organized by usage so the active workflow is easier to scan.

## Folders

- [guide](./guide)
  Workflow rules, operating guide, and automation specification.

- [planning](./planning)
  Master plan, active tracker, project document index, and durable planning references.

- [runtime](./runtime)
  The current baton state and the current developer brief.

- [logs](./logs)
  Developer history, reviewer outcomes, debugger log, and manual suggestions log.

- [manual](./manual)
  Manual support templates such as debugger calls and suggestions/improvements capture.

- [personas](./personas)
  Reusable persona contracts and prompts.

- [temp](./temp)
  Temporary cycle-scoped notes and session summaries.
