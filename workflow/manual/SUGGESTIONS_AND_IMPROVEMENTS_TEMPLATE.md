# Suggestions And Improvements Template

Use this file when you want to manually record:

- product improvements
- UX polish requests
- small workflow adjustments
- minor technical adjustments
- features or refinements that are not urgent bugs

This is not a debugger file.

This is also not the active baton brief.

Instead, it is the manual capture point for ideas the `Planner` should take into account when choosing or refining future cycles.

After adding a suggestion, copy it into or update [SUGGESTIONS_AND_IMPROVEMENTS_LOG.md](../logs/SUGGESTIONS_AND_IMPROVEMENTS_LOG.md) so the planner can review it during the next planning pass.

## How To Use

1. Copy one template block below.
2. Fill in the idea, desired change, and why it matters.
3. Add it to [SUGGESTIONS_AND_IMPROVEMENTS_LOG.md](../logs/SUGGESTIONS_AND_IMPROVEMENTS_LOG.md).
